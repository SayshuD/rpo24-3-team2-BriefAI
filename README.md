# BriefAI

**BriefAI** принимает учебный файл (.txt или .docx), извлекает текст, отправляет его
локальной модели через Ollama и возвращает структурированный конспект: тема,
определения, примеры, выводы.

## Что умеет сервис

- После того как пользователь загружает текстовый файл в формате .txt, .docx или .pdf, сгенерировать структурированную синтезированную выжимку, содержащую: тему, определения, примеры, выводы — объёмом не более 30 % исходного текста.
- Отображать прозрачность сжатия: каждый сжатый фрагмент подсвечивается и связывается с исходным текстом.
- Пользователь сможет скачать эти карточки.
